## Reporting issues

Bug reports for this ROM belong in the **[Issues](https://github.com/pissarro-development/LineageOS-Releases/issues)** tab of this repository or in the **[Bugs topic](https://t.me/pissarro_hub/673)** of our Telegram group.

Before opening an issue, verify that you are on the latest release and using the recommended firmware and kernel. A useful report must include:
- Exact ROM version and build date
- Regional firmware version flashed prior to the ROM
- Recovery used and installation type (clean flash vs. dirty flash)
- Any root solution or third-party modules installed (Magisk / KernelSU / Zygisk)
- Relevant logs (`logcat` for userspace crashes, `dmesg` or `ramoops`/`expdb` for kernel panics and random reboots)
